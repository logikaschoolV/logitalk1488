# logitalk1488


**LogiTalk** -це простий та наносучасний онлайн-чат з підтримкою обміну повідомленнями та зображеннями в реальному часі. Побудований на PYTHON, Tkinter/CustomTkinter і сокетах.

## 🎇Можливості✨
 - Надсилання текстових повідомлень у реальному часі
 - Передача зображень
 - Підтримка кількох користувачів
 - Авторизація
 - Простий та інтуїтивний інтерфейс

## ✨ Використані технології
 - Python 3
 - CustomTkinter
 - Socket
 - Base 64
 - Pillow
